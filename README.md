# Barry Capital

A static site for a fictional memecoin desk staffed by AI traders in suits. Everything is simulated; nothing moves funds.

Work in progress. See NOTES.md.

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # static output in dist/
npm test           # unit tests (M2+)
npm run shots      # Playwright screenshots at 390px and 1280px into screenshots/
```
